# RecSys Radar · 推荐算法知识库

每天从 arXiv 捞推荐系统相关的新论文，人工（AI）筛一遍，只留下值得读的，按「今天到底在发生什么」组织，而不是按投稿流水账。

**范围**：推荐系统核心 + 生成式推荐 / Semantic ID + LLM4Rec + 排序/召回工程实践
**来源**：arXiv `cs.IR` / `cs.CL` / `cs.AI` / `cs.LG`
**节奏**：每天早上更新一次（窗口为过去 2 天，周末合并到周一）

    2026-10-29.md
  2026-W45/

xhs/
  2026-W44/              # 同一天的 ISO 周
    2026-10-28.md        # 小红书文案（标题/正文/标签）
    2026-10-28.png       # 封面 1080×1440

`daily/` 是日报全文，`xhs/` 是同一期的小红书版本（文案 + 封面图）。两边都按 ISO 周分文件夹，一天一组，文件名就是日期。跨周不拆：一期的窗口可能横跨两周，但文件归到「发布当天」所在的那一周。

## 怎么读

- **精读**：给了「一句话结论 / 为什么重要 / 能拿走什么」三段的，是我认为值得花 20 分钟以上的。
- **扫读**：一张表，一句话说清这篇在干什么，需要时再点进去。
- **负结果与反思**：单独点名。这类论文短期不涨点，但改的是你对系统的判断。

## 维护

- 抓取脚本：`fetch_arxiv.py`（arXiv API + 关键词过滤 + 去重）
- 每天流程：拉新论文 → 过滤去重 → 读摘要 → 写日报 → 推送飞书 → 提交仓库
- 论文只记 arXiv id 与链接，不搬运全文；摘要级判断 + 自己的评论。
